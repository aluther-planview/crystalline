# A déjà vu is usually a glitch in the Matrix.

Two folders for one topic, an edit that changes nothing but still writes: both look like progress and are not. Crystalline now points out the first and skips the second.

## New & Noteworthy

**A new folder next to a close one.** An agent that captures a lot can start `projects/planview` when `projects/planview-work` already holds the same topic. The capture skill says to reuse the domain's folders, but an agent that never read it does not know. Now the server notices: when a write starts a new folder and a folder next to it has a close name, the answer says so.

- It names the close folders and how many engrams each holds, and suggests `move_engram` if it is the same topic.
- Close means one of three things. The same name apart from case or `_` and `-` (`plan_view`, `plan-view`). One name plus more words (`planview`, `planview-work`). One or two letters apart (`note`, `notes`).
- Not close: a shared start alone (`project`, `projection`) and names that differ only in digits (`week-01`, `week-02`).
- The hint comes with `write_engram`, a `POST /engrams` and `crystalline write`. It never refuses or changes a write.

**Close folders in evolve.** For domains that already have such pairs, the maintenance sweep reports them as V112, one finding per pair. If the two folders are meant to be separate, acknowledge the finding: it stays quiet until one of the folders is renamed. The acknowledgment can sit on any engram of the two folders, and `remove V112` takes it back from all of them.

## Fixes

- `edit_engram` `set_frontmatter` on `tags` or `sources` wrote the list in a different style than `write_engram` (indented and quoted). The first edit after a write changed lines it did not touch, which made a noisy diff in a team domain. Both now write the same style.
- A `set_frontmatter` that changed nothing still wrote the engram: a new provenance stamp and a new checksum, and a team domain had a change to share. Now it writes nothing and the answer says `unchanged: true`. An outdated `expected_checksum` is still refused.
- On a narrow phone screen the top bar of Fluid left almost no room to type.
- On Windows a search or a write failed now and then with "permission denied" for a temp folder. The database creates such a folder for some queries, and Windows sometimes refuses it for a moment. Crystalline now tries the query once more.

## Changes

- The capture skill now shows a source whose unit is a block or a paragraph anchor. It says there is one record engram per source that each run updates. And it says to make no call when the list of sources is unchanged.
- When an agent finds an engram that is wrong and it cannot fix it, the skills now tell it to ask you. It names the engram with its link, says what is wrong and what source shows it, and suggests the fix. Where it may write, it still writes the correct fact and links it to the wrong engram. This covers a read-only domain, an engram with your own words or decisions and an engram the agent may not write.
- On Postgres, the first start of 0.25.2 adds one index. Writes pause for a few seconds while it is built.

## Breaking changes

None.
