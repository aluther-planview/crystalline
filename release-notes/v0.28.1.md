# On screen.

Fluid opens a domain on its Reflection now. The engrams are one click away.

## New & Noteworthy

**The Reflection comes first.** The Reflection is where people read, edit and discuss what the agent knows. Browsing the engrams themselves has become the exception: it is how you look into the agent's memory when something seems off. So Fluid now opens a domain on its Reflection, if the Reflection is on and you may read it. In every other case it opens on the engrams, as before.

- The switch at the top reads "Reflection | Engrams" now, with the Reflection first.
- The engram view has its own address: `/d/<domain>/engrams`. Folders open there too.
- Old links keep working. A link to `/d/<domain>` follows the rule above, and an old folder link opens the folder in the engram view.
- People who may read the Reflection but not the engrams land on the Reflection too.

## Changes

- Scripts that open `/d/<domain>` and expect the engram list now land on the Reflection when it is on. Use `/d/<domain>/engrams` for the engram list. Fluid has no public UI contract, so this is not a breaking change, but a script that clicks through Fluid may need an update.

## Breaking changes

None.
