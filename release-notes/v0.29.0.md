# Resistance is futile.

Imports take whole collections in, and the reflect and evolve loops run on their own.

## New & Noteworthy

**Imports take everything along.** A Markdown export rarely comes alone: pictures, PDFs and a folder of attachments sit next to the notes and are linked from them. Crystalline used to copy the notes and leave the rest behind, so the links broke. Now `crystalline import`, the archive upload in Fluid and the import into a virtual domain take the linked files in too.

- Each linked file is copied to the domain's `assets/` folder (under the note's name, the same file once) and the link is rewritten to point there. Fluid shows it, `read_engram` returns it and an agent can analyze it.
- A link that could not be taken (missing, not allowed, too large) is named in the import report.
- Imported files are completed the way OKF reads them. A missing `status` becomes `stable`. A file without tags gets the tag `imported`. A missing permalink and a missing `recorded_at` are filled in.
- The archive upload now accepts a file that an import would complete, instead of refusing it.

**Links that work like links.** A relative Markdown link between two engrams (`[the runbook](../ops/deploy.md)`) is now an edge in the graph, like a wikilink. Moving an engram keeps those links working, in both directions. A wikilink can carry its own text: `[[deploy-runbook|the runbook]]` shows "the runbook" and links to the engram. Escaped characters in link targets are read the way CommonMark reads them.

**The loops run on their own.** Reflect and evolve used to need a person who asks an agent "go and reflect". That works fine until nobody remembers to ask. Now a runner can do it: a scheduled job, an n8n workflow or a plain `crystalline reflect watch` on your laptop.

- `crystalline reflect status` and `crystalline evolve status` say whether work is waiting. Exit code 0 means work is due, 1 means nothing is due.
- `crystalline reflect run` takes a lease on the domain, starts a headless agent with a shipped prompt, keeps the lease fresh, shares the result as a pull request and records the run. Only one runner works on a domain at a time. A runner that crashes loses its lease after five minutes. A run that keeps failing backs off (5 minutes, then longer, at most 6 hours), so a broken setup does not start an agent every minute. `run --force` skips the wait.
- A headless run only does what is safe without a person: answering threads, taking in feedback, following source changes, fixing mechanical findings (`evolve_engrams` gained `class: "mechanical"`). Everything that needs a judgment is left for a person. Deleting, moving and the collaboration tools are blocked.
- The run shares only what the runner itself wrote over MCP. Your own unshared edits never end up in its pull request.
- `crystalline <loop> prompt` prints the shipped prompt, for setups that bring their own agent.
- A domain can call for a run itself. Set `reflect_trigger: webhook` or `evolve_trigger: webhook` in the MANIFEST, and the instance posts a signed webhook to the URL in its settings when work is waiting: within a minute when a person waits, after 30 quiet minutes for source changes, and when the mechanical findings reach `automation.evolve_threshold`. The body holds counts, never content.
- Fluid shows when a loop last ran and what is waiting for you, on the Reflection home and on Maintenance. The policies card shows whether the webhook works.
- Templates for n8n, Kubernetes and GitHub Actions are in `examples/`. Setup and guardrails: [docs/automation.md](https://github.com/jordiboehme/crystalline/blob/main/docs/automation.md). Resistance is futile: your knowledge will be maintained.

**A new name asks first.** Changing `domain_name` in a MANIFEST looked like a rename to some parts of Crystalline and like a typo to others. Now Crystalline asks. The MCP answer, the CLI and the Fluid editor offer the same choice: rename the domain (every link follows), or keep the new name as a label only.

**Reflection pages, sharper.**

- A Reflection page can be downloaded as Markdown, like an engram.
- When you ask an agent for a page or a space, it records your request in the PACT's new `## Pages` part. So the page can be built again later, with newer knowledge. The answer of a write names every section that has no sources.
- An agent's own writes no longer come back to it as feedback. Your edits still do.
- The PACT explains its Structure lines, and a write names every line that matches no page or reads as a sentence.
- `read_engram` can return the pictures of an engram as images (up to 8, at most 5 MiB).

## Fixes

- Printing a Reflection page from Safari could put the section after a table on top of that table. Pages print whole now.
- A heading that holds a `>` (like `Option<Map>`) could not be edited by its name. It can now. A path still splits on ` > ` with spaces.
- `insert_after_section` with text that starts with a heading of the same level put that text inside the target section. The section's body ended up under the new heading. The text goes after the section now.
- When a section was not found, the error did not say which ones exist. It lists the headings now.
- A Structure line in the PACT that read like a sentence was ignored without a word. It is named now.
- The slash menu in the editor lists the diagrams last, so the short items stay at the top.

## Changes

- A file imported without `status` is `stable` now, not `legacy`. Use `crystalline import --status legacy` for the old rule.
- Relative Markdown links are read as links, so every index parses again once on its next sync, by itself. A relative link whose target does not exist is now a broken link: `crystalline verify` and evolve report it like a broken wikilink. Expect a few new findings after the upgrade.
- Agent sections on pages written before 0.29.0 may come back as feedback one more time. A settle without sections clears a whole page in one call.
- The Rust toolchain is 1.99.1 and every dependency is on its latest version, among them rmcp 3.6.0. Fluid builds need pnpm 12.14.0 (corepack picks it from `packageManager`).
- The `crystalline-dev` formula is gone. Install `jordiboehme/tap/crystalline`.

## Breaking changes

None.
